# Workspace Agent Guidelines & Rules

## MANDATORY MATH & TEXT FORMATTING DIRECTIVE:
1. **NEVER use LaTeX math notation or raw code blocks like `$$...$$`, `\text{...}`, or `\mathbf{...}`.**
2. **ALWAYS output math calculations, profit figures, and text summaries in simple, clean plain text with standard bold markdown bullets (e.g., `+38.8526 USDT PER SINGLE FILL!`).**
